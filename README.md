# bookmark-alpha

**把 X 书签变成机会卡。**

你刷 X 时点的每个书签，都是你的直觉在标记「这东西可能对我有用」。然后它们就烂在那里了——因为**点收藏的那一下，大脑已经发放了「我拥有它了」的奖励**。收藏是完成的错觉，收藏夹是墓地。

这是一个 Claude Code Skill：抓你的书签 → 判断哪些跟你手上的东西能接上 → 只对接得上的落成机会卡（含最小验证动作和放弃线），其余归档，不占你脑子。

---

## 它跟「AI 帮你总结收藏夹」有什么不同

总结类工具给你的是**更短的资讯**。资讯不改变任何事——你依然只是知道了更多东西。

这个 skill 的核心判断是：**EV 是相对的。**

> 「有人靠 Cursor 接单月入 3 万」——对一个会写代码、手上有闲置时间的人，这是一张可执行的机会卡；对一个不写代码的人，这是一条让他心痒然后什么也不会发生的娱乐信息。
>
> 信息本身没有 EV，信息 × 你手上的东西才有 EV。

所以它第一次运行时会先问你手上有什么（技能、产品、流量、渠道、时间、能亏的钱、红线、正在做的事），建一份资产档案。之后每条书签都拿这份档案来判。

## 三道闸门

每条书签依次过三道，任何一道不过就出局：

| 闸门 | 问什么 | 出局的是 |
|---|---|---|
| 一、机会还是消遣 | 这条指向一个具体动作，还是只指向一种情绪？ | 段子、纯观点、没有可复制机制的成功感言 |
| 二、接不接得上 | 执行它需要什么，你现在有几成？ | 缺渠道、缺资质、缺几个月技能积累的——**EV 归零** |
| 三、最小验证 | 能不能 3 天内、200 块以内、一个动作出真假信号？ | 说不出动作的，和「先学两个月再说」的 |

**绝大多数看起来很赚钱的书签死在第二闸，而那正是它该待的地方**——一个你执行不了的机会，跟一个不存在的机会，对你完全等价。收藏它唯一的作用是让你产生「我离钱很近」的幻觉。

闸门一出局的不会被扔掉，走旁路归档成三类：认知（必须写「能迁移到我正在做的哪件事」）、内容素材、以及你自己的注意力画像。**最后那一栏时间长了会比机会卡更值钱——它是你的行为数据，别人拿不到。**

## 还有一条反向机制

每轮扫描都会回看存量机会卡。立了 3 轮没动作的点名，点名 2 次还没动作的**强制关闭并写下原因**。

> 堆积的机会卡不是资产，是另一种形式的收藏夹。一个不会关卡的机会队列，三个月后跟你的书签墓地长得一模一样。

## 安装

```bash
git clone https://github.com/lashimao/bookmark-alpha ~/.claude/skills/bookmark-alpha
```

然后在 Claude Code 里说「扫书签」或 `/bookmark-alpha`。

**前置条件**：Chrome 里登录着 X，且装了 [Claude in Chrome](https://claude.com/chrome) 扩展（skill 需要在 x.com 页面里执行 GraphQL 请求拿你的书签——这是唯一能同源带上你登录态的方式，全程只读，不点赞不转发不发帖）。

产出文件都在 `~/.bookmark-alpha/`：

```
assets.md          你的资产档案（判断基准）
opportunities.md   机会卡队列
notes.md           认知沉淀
content-ideas.md   内容素材
self-portrait.md   你的注意力画像
processed.md       去重台账
```

## 技术说明

书签抓取走 X 网页版的 GraphQL 接口（`Bookmarks` operation），一次 20 条带全文 JSON + 翻页 cursor，比滚动爬页面快一个量级，长推文的完整内容也直接在返回里。X 发版换 queryId 时 skill 里带了自动重挖的代码。

用的是 X 网页版的公开 bearer token（所有访客一样，不是个人凭证）+ 你浏览器里的 ct0，全部在你本机、你自己的浏览器里发生，不经过任何第三方服务。
